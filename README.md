# からだミッション 第2版

「何を食べるか考えなくていい」iPhone向けダイエットアプリ（PWA）。
費用0円・Mac不要・データはiPhoneの中だけに保存。

## 入っているもの

```
app/                       ← この中身をそのまま公開する（全部同じ階層）
  index.html / style.css
  db.js          端末内保存・バックアップ/復元
  engine.js      目標計算・ミッション生成（オフラインで動く）
  services.js    Gemini（任意）・近くの店検索・通知
  importer.js    店舗・メニュー・商品のJSON取り込み（第2版で追加）
  ui.js          各画面
  sw.js / manifest.webmanifest / icon-*.png
  products.json  コンビニ商品（公式サイトで確認済み116品）
  chains.json    チェーン店（同梱データ）
samples/
  karada-stores-sample.json      取り込み用JSONの形式サンプル
  CHATGPT_PROMPT.txt             ChatGPTに渡す指示文
  test-store-for-check.json      動作確認用（架空の店。確認後は削除）
tools/                           第1版のデータ作成スクリプト
CHANGES_v2.md                    第2版の変更点・確認済み/未確認の動作
DATA_STATUS.md                   データ取得状況
```

## 第1版から更新する場合

GitHubのリポジトリで、`app` の中のファイルを**全部**上書きアップロードしてください（新しく `importer.js` が増えています）。
同じURLのまま更新すれば、iPhoneに保存されている記録・体重・行きつけ店などはそのまま残ります。
念のため、更新前に「裏 → バックアップと復元」で写真込みのバックアップを取っておくと安心です。

## 1. 無料で公開する（GitHub Pages・iPhoneだけでも可）

1. Safariで github.com を開き、無料アカウントを作成
2. 右上「＋」→「New repository」→ 名前 `karada`、**Public** で作成
3. 「uploading an existing file」→ `app` フォルダの中のファイルを**全部**選んでアップロード → 「Commit changes」
4. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして Save
5. 1〜2分後、`https://（ユーザー名）.github.io/karada/` で開けます

公開されるのはプログラムと商品データだけです。記録やAPIキーはGitHubに送られません。

## 2. iPhoneのホーム画面に追加（重要）

1. 上のURLを **Safari** で開く → 共有ボタン（□↑）→「ホーム画面に追加」
2. 以後は必ずホーム画面の「からだミッション」から起動

**Safariで開いた時とホーム画面のアプリでは、保存データが別になります。**
Safariで開くと画面上部に案内が出ます。Safariで記録してしまった場合は、Safari側で「裏 → バックアップ」→ アプリ側で「復元」してください。

## 3. ChatGPTで店舗・メニューを増やす（API接続なし）

1. アプリの「裏」→「ChatGPTから店舗を追加」→「ChatGPT用の指示文をコピー」
2. ChatGPTに貼り付け、最後に店名（例：天丼てんや）を書いて送る
3. ChatGPTが作ったJSONファイルを、iPhoneの「ファイル」アプリに保存
4. アプリで「JSONファイルを読み込む」→ 登録・更新・重複・エラーの件数を確認 →「取り込む」

- チェーン店・個人経営の店・コンビニ商品、どれも同じ方法で追加できます
- 同じidの店・料理は重複せず更新。既存チェーン（松屋など）に追加すればメニューが増えます
- エラーの項目だけ除いて取り込みます。ファイルが壊れている時や保存に失敗した時は、既存データは一切変わりません
- 個人店は住所・緯度経度があれば「現在地から探す」で優先表示されます
- 取り込んだ店は「裏 → ChatGPTから店舗を追加」の一覧から削除できます
- 形式は `samples/karada-stores-sample.json`、指示文は `samples/CHATGPT_PROMPT.txt`

### JSON形式（要点）

```json
{
  "format": "karada-data", "version": 1,
  "stores": [{
    "id": "tenya", "name": "天丼てんや", "type": "chain", "genre": "牛丼・定食",
    "aliases": ["天丼てんや","てんや"], "address": null, "lat": null, "lon": null,
    "officialUrl": "https://...", "verifiedAt": "2026-10-05",
    "items": [{
      "id": "tenya-yasai-tendon-nami", "name": "野菜天丼", "size": "並", "category": "main",
      "priceYen": 690, "nutrition": {"kcal": null, "protein": null, "fat": null, "carbs": null, "salt": null},
      "allergens": {"status": "unknown", "contains": []},
      "officialUrl": "https://...", "verifiedAt": "2026-10-05", "status": "active"
    }]
  }],
  "products": []
}
```

- `type`: chain（チェーン）/ local（個人店）
- `category`: main / side / drink / alcohol / dessert
- `allergens.status`: 公式アレルゲン表で確認できた時だけ `confirmed`、それ以外は `unknown`
- 不明な値は `null`（アプリは不明のまま扱い、数値を作りません）

## 4. 毎日の使い方

- 朝：「今日の予定」→ 仕事/ゴルフ/ソフトボール/休日/出張 と、朝食・昼食・夕食の買い方を選ぶ（まとめ買いは任意）
- 食べる時：ホームの「朝食・昼食・夕食」→ 店を選ぶ → 指令どおり買う →「撮影してクリア」（AIなし・上限時は手動でクリア）
- 指令は正式な商品名・味・個数、チェーンは料理名・サイズ・組み合わせまで指定。ほかの組み合わせ案も表示
- 売り切れ・アレルギー・体調不良・量不足・予定変更は何度でも変更OK。気分での変更（別案を選ぶ含む）は1回まで
- 栄養成分が不明な商品が入っている時は、「目標を満たしているかは判断できません」と表示します
- 夕食が家ごはんの日は写真で記録するだけ

### アレルギーについて

アレルギーを登録すると、**公式のアレルゲン情報が確認できている商品だけ**をミッションに使います。
同梱の116品はアレルゲン情報を未登録のため、アレルギー登録時はコンビニのミッションが出ない場合があります。
ChatGPTでアレルゲン確認済みのデータを追加するか、「裏 → 好き嫌い・アレルギー」で「未確認の商品も表示（自分でラベル確認）」を選んでください。

## 5. 現在地からお店を探す

- 位置情報は通常OFF。「この範囲で探す」を押した時だけ、確認してから1回取得（追跡・保存なし）
- 徒歩5/10/15/20分は**直線距離による目安**です（道路に沿った時間ではありません）
- 位置を登録した行きつけ店・取り込み店を最優先で表示。登録チェーンは登録メニューからすぐ指令
- 未登録の店はメニュー表の写真をAIが読んで選ぶ。検索に失敗しても店名の手入力で続行可能

## 6. AI連携（任意・無料枠）

Safariで https://aistudio.google.com →「Get API key」→ アプリの「裏 → AI連携」に貼り付け。
- キーは端末内だけに保存（GitHub・バックアップには含まれません）。端末内保存も完全に安全ではないので、このアプリ専用のキーを作り、課金は有効にしないでください
- AIなしでも登録データでミッションは動きます

## 7. 写真

写真はすべて端末内。「裏 → 写真の整理・削除」で1枚ずつ／30日・90日より前をまとめて削除できます（全身写真は自動では消えません）。

## 8. バックアップと復元

「裏 → バックアップと復元」。写真込み／記録のみ を選んで保存。
- 含むもの：プロフィール・記録・体重・取り込んだ店舗・追加商品・行きつけ店・自販機・写真（選択時）
- 含まないもの：APIキー
- 復元前に中身（日数・写真枚数）を確認し、「今のデータを先にバックアップ」できます。書き込み後に読み戻して確認します。失敗時はデータを変更しません

## 9. 通知・ヘルスケア

- 通知：無料のPWAでは閉じている時の予約通知ができないため、開いている間の通知＋カレンダー(.ics)登録で対応
- ヘルスケア：iPhoneの「ショートカット」で `（アプリのURL）#hk?steps=歩数&weight=体重` を開くと取り込み（第1版の `#import?steps=` も引き続き使えます）
